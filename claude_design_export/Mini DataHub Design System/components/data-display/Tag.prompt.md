Tag / badge pill for facet labels (embodiment, format, license, quality, failure flags).

```jsx
<Tag tone="accent">bimanual</Tag>
<Tag tone="success">可商用</Tag>
<Tag tone="danger">含失败</Tag>
```

Tones: `neutral` (slate), `accent` (indigo), `success` (emerald), `warning` (amber), `danger` (rose) — 1:1 with the source app's `TONES` map.
